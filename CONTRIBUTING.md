# Contributing to XO License

XO License is built in the open. Contributions of every size are welcome.

Created by **OTTAHEN (ℒ)** · https://github.com/Ottahen

## Ways to Contribute

- Review the license text and report ambiguities
- Propose improvements to the `XO-ORIGIN.json` format
- Build tools, integrations and examples
- Translate documentation
- Test compatibility with other licenses
- Report issues and suggest features

## Before You Start

1. Search existing issues to avoid duplicates.
2. For major changes (license text, schema, obligations), open an issue and discuss first.
3. Small fixes such as typos and clarifications may go straight to a pull request.

## Pull Request Process

1. Fork the repository and create a branch.
2. Make your change and keep the scope focused.
3. Update documentation and `CHANGELOG.md` where relevant.
4. If your change affects the schema, update `schema/xo-origin.schema.json` and validate `XO-ORIGIN.json`.
5. Add yourself to `CONTRIBUTORS.md`.
6. Open a pull request describing what changed and why.

## Rules for the License Text

- Released versions are never silently changed.
- Changes to permissions or obligations require a new major version.
- Wording clarifications are released as patch versions.
- All changes are public and open to review.

## Contribution Terms

By contributing, you confirm that you have the right to submit your work and agree that it may be distributed under the XO License, Version 1.0. You keep ownership of your contribution, and you will be credited.

## Principles

1. Be respectful and constructive.
2. Credit everyone's work.
3. Keep documentation clear and accessible.
4. Preserve the freedoms required by the Open Source Definition.
