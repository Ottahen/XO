# Changelog

All notable changes to the XO License project are documented here.

Versioning policy:
- **Patch** (1.0.1): wording clarification with no change in meaning
- **Minor** (1.1): new optional feature or tool
- **Major** (2.0): change to permissions or obligations

## [1.0.0] - Proposed

### Added
- XO License text, version 1.0 (draft, pending legal review)
- Core permissions: commercial, personal, modification, redistribution, private modification, proprietary integration, forking, research and education
- Attribution and creator recognition system
- XO Origin Chain concept and `XO-ORIGIN.json` origin record format (draft)
- JSON schema for `XO-ORIGIN.json`
- Patent grant with scoped retaliation, trademark separation, warranty disclaimer
- 30-day cure period
- Master specification (`XO-LICENSE.md`)
- Project files: `LICENSE`, `NOTICE`, `AUTHORS.md`, `CONTRIBUTORS.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`

### Planned
- XO CLI, Compliance Checker, Attribution Generator
- XO Registry, Origin Explorer, Attribution Map
- GitHub and GitLab integrations
- Independent legal review, OSI submission, SPDX identifier request
